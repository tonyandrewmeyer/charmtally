Every denominator on this page counts only actively-maintained charms: those whose repository has seen a commit in the two years before that snapshot’s date. A charm nobody has touched since before these APIs existed is not one anyone is going to migrate, so counting it would measure abandonment rather than adoption.

Unless a card says otherwise, the denominator narrows further to eligible charms: active charms minus reactive and legacy-classic ones, which pre-date ops and could never adopt these APIs. Metrics about tooling that works whatever the charm is built on — Jubilant, say — measure against every active charm instead, and name that on the card. The corpus itself grows between scans, so read a series as a share, not as a count.
